# Vamsapattika React Website

A responsive React + Vite landing page for Vamsapattika, using the supplied Vamsapattika logo and heritage-tree image.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Assets

- `public/vamsapattika-logo.jpeg` — supplied Vamsapattika logo
- `src/assets/legacy.jpeg` — supplied heritage tree image

The design palette is derived from the logo: navy blue, teal, green, purple, pink, orange and warm cream.
